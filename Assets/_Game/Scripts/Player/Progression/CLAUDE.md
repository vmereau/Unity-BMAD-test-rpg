# CLAUDE.md — Assets/_Game/Scripts/Player/Progression

> Loaded when Claude accesses files in this folder. XP, leveling, learning points,
> and skills. **Namespace: `Game.Progression`** (not `Game.Player.Progression`).

---

## What's here & the event chain

These systems are wired together by `GameEventSO` channels, not direct calls:

```
kill → XPSystem.GiveExperience()         (per-enemy XP routed via PlayerRewards)
     → OnXPGained → LevelSystem          (fires OnLevelUp when thresholds crossed)
     → OnLevelUp  → LearningPointSystem   (awards LP per level-up)
```

| File | Role |
|------|------|
| `XPSystem` | Tracks XP + kill count. `GiveExperience(amount)` is the entry point. |
| `LevelSystem` | Subscribes to `OnXPGained`, fires `OnLevelUp` on threshold crossings. |
| `LearningPointSystem` | Subscribes to `OnLevelUp`, grants Learning Points (LP). |
| `PlayerSkills` | Set of learned skills (learned via tome pickup / other sources). |
| `PlayerRewards` | Per-enemy-type XP/reward lookup; auto-synced by an Editor tool. |

---

## Rules

- Namespace is `Game.Progression` — match it, don't introduce `Game.Player.Progression`.
- Subscribe to event SOs in `OnEnable`, unsubscribe in `OnDisable` (with the `_input == null` style guard pattern where applicable) — never in `Start`.
- `PlayerRewards` data is regenerated by an editor auto-sync (`Scripts/Editor/PlayerRewardsAutoSync.cs`) — don't hand-edit the synced asset.
